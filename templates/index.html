Features and preprocessing

The model receives these property features through the web form and applies the preprocessing defined in the saved pipeline.

  • Location — categorical property location
  • Total square feet — numerical area
  • Bathrooms — bathroom count
  • BHK — bedroom configuration
  • Location encoding and other fitted transformations
Understanding the reported scores: R² is not the percentage of predictions that are exactly correct. MAE and RMSE are expressed in the same units as the target used during evaluation. If your target is measured in lakhs of rupees, MAE ≈ ₹20.61 lakh and RMSE ≈ ₹45.85 lakh. Confirm the target units in your notebook before interpreting them as currency.
Model limitation: These are test-set results, not a guarantee of future performance. Estimates can be less reliable for unusual properties, locations with limited training examples, or market conditions not represented in the training data.
ⓘ About HomeScope

Turning property data into estimates

HomeScope is a machine learning web application built to demonstrate how a trained regression model can be used to estimate residential property prices from structured data.

⌂

Project objective

Build an interactive interface that accepts property details and returns an estimated price from a trained machine learning pipeline.

▤

Dataset

The application reads cleaned Bangalore housing data from Cleaned_data.csv. The available locations populate the location dropdown dynamically from the dataset.

⌘

Technology stack

Python handles the backend and prediction workflow. Flask serves the web pages, while pandas prepares input data and the saved Scikit-learn pipeline generates predictions.

◎

Prediction workflow

A user selects a location and enters property features. The form sends them to the Flask /predict route, which creates a DataFrame, runs the saved pipeline, and returns the predicted price.

Important: This project is an educational prediction tool. It does not account for every factor affecting real estate value, such as property condition, legal status, exact building quality, negotiation, or changing market conditions.
